# GECC1130 反思習作網頁｜我的大學路

崇基學院 GECC1130 *Idea of a University* 反思習作（約 30%）的單頁作品集骨架。  
**版面與結構已備好；所有反思正文請你自己填寫。**

## 如何開啟

1. 用檔案管理員進入本資料夾 `gecc1130-portfolio`
2. 雙擊 `index.html`，或在終端機執行：
   ```bash
   # 任選其一
   open index.html          # macOS
   xdg-open index.html      # Linux
   start index.html         # Windows
   ```
3. 亦可部署到 GitHub Pages，再把公開連結貼到 Blackboard（請依課程最新繳交說明）

### GitHub Pages（若公開網址仍係 404）

1. 開啟 [Settings → Pages](https://github.com/yoy929981-sketch/gecc1130-portfolio/settings/pages)
2. **Build and deployment → Source** 揀 **GitHub Actions**
3. 到 Actions 重跑 `Deploy GitHub Pages`（或再 push 一次）

正式網址（啟用後）：https://yoy929981-sketch.github.io/gecc1130-portfolio/

臨時預覽（唔使等 Pages）：  
https://rawcdn.githack.com/yoy929981-sketch/gecc1130-portfolio/main/index.html

## 頁面結構

| 區塊 | 內容 |
|------|------|
| 草稿工具列 | 填寫進度、本機自動儲存、複製草稿、列印／PDF |
| Hero | 標題、可編輯姓名、大學生身份（已預填方向） |
| 願景與使命 | 已預填事實方向 + 圖像提問 |
| 三大 SMART 目標 | 空間規劃／First Honour／Mobility 賦權；各含課堂連繫空白 |
| 行動時間線 | 現在 → 2026-12 → 2027-05 |
| 身心社靈 | 四格短填 |
| 檢討機制 | 週期／方法／肯定 |
| 結語與承諾 | 空白 |
| Footer | 課程資訊與 AI 政策提醒 |

## 你要填什麼

- 所有虛線框、標示「【請在此填寫…】」的地方
- Hero 的姓名
- 目標 3 的 A/R 資源欄（若需要）
- 瀏覽器頂部工具列會**自動把草稿存進本機**（localStorage）；換裝置唔會同步
- 可用「複製草稿文字」貼去 Word，或「列印／存 PDF」備份

### 較穩妥的寫作方式

1. 先在 Word／Google 文件寫完 800–1,000 字
2. 再把各段貼進對應區塊（亦可直接改 `index.html`）
3. 瀏覽器開啟檢查手機版與列印預覽

## 字數提示

- 課程要求約 **800–1,000 字**（中文）
- 預填的願景／SMART 標籤／課堂提示**不算**你的反思正文
- 網頁本身不自動計字；請用文件字數統計

## 重要：AI 使用政策

- 本網站僅提供**結構、版面與已確認的事實標籤**
- **禁止**用生成式 AI 代寫任何書面作業正文
- 如有疑問可向 `cccge@cuhk.edu.hk` 查詢
